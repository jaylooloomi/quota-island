# 設計稿實作：0.2.0

實作截圖（展示資料）：[主面板](implemented-0.2.0-expanded.png)、[收合列](implemented-0.2.0-compact.png)、[連接完成](implemented-0.2.0-connection.png)。使用者參考圖：[原圖](reference-v2.jpg)。

本次參考使用者提供的深色 Quota Island 設計圖，以可互動 HTML/CSS/SVG 還原主面板、收合列與連接元件。

- 配色、字級、字型、邊框、圓角、留白、狀態位置與進度條依稿調整。
- 正常展示內容是 Claude 兩個窗口、Gemini 兩個模型、Codex 一個窗口；只在展示模式使用圖中的範例數值。
- 真實模式使用服務回傳的數字。Gemini 個人版標為 Antigravity；模型名稱、方案名稱與窗口數依真實回應顯示，不寫死 Pro/Flash/每週。
- 連接詳情可從卡片狀態開啟，包含四階段進度、授權碼、重開授權頁、重新連接與來源資訊。完成後自動返回配額卡片。
- 未連接、讀取失敗、舊資料與限流都有明確文字。429 冷卻跨重啟保留。
- 收合、展開與卡片排序共用偏好；首次升級以「剩餘」模式呈現，之後保留選擇。

原圖是包含多種狀態的設計展示板，不是單一巨型桌面視窗。實際應用會依狀態顯示對應元件；不把所有示範同時塞進動態島。真實服務資料、系統縮放、字型反鋸齒會與生成圖像有差異，不能把設計稿的 JPEG 像素當作真實配額或宣稱逐像素完全相同。

設計驗證：`npm run test:design`。圖像與報告輸出到 `test-results/design-*.png`、`test-results/design.json`。成品可透過 `QUOTA_PACKAGED_EXE` 指定路徑後執行同一套驗證。
