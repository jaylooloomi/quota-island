# 太空救援隊：實作與驗收

版本：1.4.0。採用使用者選定的 02 設計。

| 服務 | 角色 | 姿勢 |
| --- | --- | --- |
| Claude（含獨立帳號） | 橘色太空貓 | 待機、疲累、休息 |
| Codex | 白色維修機器人 | 待機、電池補給、休息 |
| Antigravity | 紫色星兔 | 待機、注意能源、休息 |

素材由 imagegen 獨立繪製為透明 3×3 PNG，存於 `src/ui/pets/space-rescue.png`。使用 CSS 選擇姿勢並做位移與跳躍，不需要影片播放器或額外網路請求。

## 顯示與互動

- 平常視窗維持 464×76。每 2–5 分鐘隨機出現一隻角色，在 74px 品牌區活動約 4.5 秒，期間隱藏名稱與版本；配額列不移動。
- 告警舞台暫時增加 112px，高度為 188px，原配額列保持可見。
- 0–1.8 秒：顯示實際帳號、配額窗口與剩餘百分比，角色疲累。
- 1.8–4.4 秒：切換休息／補給姿勢，機器人靠近、星兔跳躍；結束自動收回，可隨時關閉。
- 設定頁提供「待機小寵物」「配額告警小劇場」與「預覽救援隊」。預覽標示展示資料，不消耗告警記錄。
- 展開面板、拖曳整座視窗或供應商、隱藏視窗時暫停；不額外取得焦點。
- 減少動態時不演待機動畫，告警採靜態舞台。

## 告警判斷

- 在剩餘 20%、5% 與用盡時產生三種嚴重程度。
- 僅採用已連接且啟用、可見、10 分鐘內的成功讀取，並要求有效的未來重置時間。
- 登出、限流、讀取失敗與過期配額不當作用量耗盡。
- 以帳號 ID、配額窗口 ID、重置時間與嚴重程度組成去重鍵，存於本機 renderer storage。較嚴重告警會同時涵蓋較低程度，不會降級重播。
- 多帳號各自計算；帳號輪播不觸發新告警。同一時間只演一段，相鄰演出至少間隔 30 秒。

## 驗證

- `test/pet-policy.test.cjs`：門檻、重置週期、多帳號去重、錯誤資料排除。
- `scripts/pets-desktop-test.cjs`：待機替換品牌、固定配額位置、188px 舞台與76px 還原、姿勢切換、關閉、跨重載去重、四語與減少動態，以及沒有 refresh IPC。
- 四語設定頁測試、既有版面與完整單元測試一併執行。測試使用展示資料，不修改實際配額。
- 本次原生驗證為 Windows；其他平台原生視窗及不同縮放／多螢幕仍需對應環境人工驗收。

電子雞經驗值、成長階段及造型解鎖不包含在本次角色演出功能，保留為後續需求。
