# 寵物動作方案成品（v1.5.0）

原版三姿勢切換缺少中間動作，因此容易像貼圖跳換。本次保留原版，增加兩種可直接使用的播放器與素材。

| 選項 | 實作 | 適合 |
| --- | --- | --- |
| 原版 3D | 原有三姿勢及 CSS 動作 | 比較基準，保留原外觀 |
| 柔順 3D（預設） | 新姿勢分格、格間淡化、輕微呼吸緩動 | 偏好柔和立體外觀 |
| 像素逐格 | 新像素素材、清楚分格、停用影像平滑 | 偏好電子寵物／遊戲風格 |

新版本的貓與機器人各有 12 張獨立動作圖；星兔使用 6 張完整姿勢，正反循環成 12 個時間步驟。這是 2D 分格動畫，不是即時 3D 骨架動畫。產生素材底部不完整的姿勢不投入播放。

## 播放與品質處理

- 依素材實際列範圍切片，裁除透明邊緣並統一角色比例與腳底基線，避免切格時忽大忽小。
- 3D 版以相鄰格的透明度混合；像素版以逐格播放，不使用模糊插值。
- 僅在待機演出／告警舞台開啟時使用 requestAnimationFrame；關閉、隱藏、拖曳或展開面板後取消。
- 減少動態時繪製固定第一格，不執行分格循環。
- 共用既有帳號告警去重、agent 中心對齊與視窗還原邏輯，不增加同步請求。
- 在「設定 → 寵物動作風格」切換，再按「預覽救援隊」。選擇會保存並在重啟後還原。
