# 隨機散步陪伴（v1.6.0）

保留柔順 3D、原版與像素告警演出，另外加入單隻柔順 3D 散步模式。

- 設定 →「叫出散步寵物」：隨機角色出現 24 秒，可隨時關閉；連續兩次避免重複同一角色。
- 開啟「自動散步陪伴」：收合狀態每 2–5 分鐘隨機來訪。此開關預設關閉，保留原本顯示習慣。
- 角色沿舞台內的隨機目標走動、轉向、休息，再繼續走；起步及停止有加減速。
- 專用透明踏步素材，每個角色 12 格。腳步進度配合移動速度，轉向使用鏡像，停下時停止踏步。
- 散步不表示帳號配額；角色名稱與提示會明確標示「太空散步」。
- 告警優先，可接替散步；舊救援演出仍保持三個角色與 agent 置中。
- 配額列位置及寬度不變；出現時使用原有 112px 舞台，關閉後還原。
- 拖曳、隱藏、展開主面板與監控暫停時停止。減少動態時不自動散步，手動叫出為靜態陪伴。
- 不查詢配額，不消耗 token，不改變自動 Hello 或原有告警選項。

驗證：`test/pet-wander.test.cjs` 覆蓋邊界、速度、休息與格數；`scripts/pet-roaming-test.cjs` 驗證手動叫出、實際移動與分格、隨機角色、告警接替、減少動態、自動來訪與設定持久化。原三種動作方案及四語設定頁一併回歸。
