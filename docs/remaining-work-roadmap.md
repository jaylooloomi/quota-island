# 後續工作與驗收

分支：`codex/remaining-work-roadmap`。更新：2026-11-04（台灣時間）。

依序處理，每項區分實作、程式測試與自然任務／平台實測。

1. [ ] 本機 Claude Code 漏抓：比對原生 session 登錄、桌面 Code session metadata 與既有程序；不能以存在聊天、CPU 或舊紀錄判為執行中。使用者已確認問題發生在這台電腦的 Claude Code。
2. [ ] Claude／Antigravity 狀態轉換：驗證執行、等待、正常完成、取消、斷線；無自然轉換時明列未驗收，禁止為測試啟動推理或 CLI。
3. [ ] 跨電腦：分別研究兩家官方已授權來源；不使用 Hook、不啟動 CLI、不架私人接收端，不沿用 Codex 身分冒認其他服務。
4. [ ] 平台成品：為目前版本觸發 macOS 原生 CI 建置與冒煙測試，成功後上傳對應 Release；Linux 建置及桌面／縮放／多螢幕驗收分別記錄，CI 不等於所有平台人工驗收。
5. [ ] 電子雞成長：先使用可驗證的配額增量（百分點）建立本機經驗值，處理重置、多窗口、多帳號及重複快照，不虛構實際 token 數，不鼓勵浪費使用量；保留角色辨識與固定布局。
6. [ ] 外部訊息：RSS／Atom 唯讀接收、來源管理、去重、限量佇列、暫停／靜音與寵物純文字泡；不執行外部內容，限制大小與網路頻率。
7. [ ] 文件：更新舊版本能力聲明，將歷史研究與目前支援分開，補齊設定、限制與驗證入口。

每完成一項提交對應變更與證據；未通過的項目保持未勾選。Windows 發布基準為 v1.28.2。
